# V2.5: Complementary Mesoscale Models — Spatial PDE + Contact Network

## Motivation

The current modeling stack has two endpoints with a large gap:

| | Mean-Field ODE | Full DEM |
|---|---|---|
| **DOF** | 1 scalar (x_f) | N × (pos + orient + cells) |
| **Spatial info** | None | Full particle resolution |
| **Topology** | None | Full contact graph |
| **Cost** | Milliseconds | Hours (3D) |
| **Fits to data** | 3 params | Forward only |

Two complementary mesoscale models fill orthogonal parts of this gap:

1. **Spatial PDE** — answers *where* compaction happens (spatial gradients, porosity profiles, permeability maps)
2. **Contact Network** — answers *how* the packing reorganizes (bridge percolation, force chains, coordination evolution, cluster statistics)

Together they provide spatial + topological resolution at ~seconds cost.

**Cross-feeding between models:**
- PDE → Network: Local packing fraction φ_f(ξ) sets expected coordination number Z(ξ) for graph edges
- Network → PDE: Percolation state and mean Z from graph inform effective viscosity η_eff(ξ) in PDE
- Both → Descriptors: Each model produces the 18 tissue descriptors for organ distance computation

## Model 1: Spatial PDE (`analysis/spatial_pde.py`)

### What it captures
- Spatial compaction profiles (compaction waves propagating inward)
- Local jamming fronts
- Heterogeneous porosity and permeability profiles
- Tissue volume evolution with spatial resolution
- Direct comparison to experimental confocal radial profiles

### State variables
On a 1D grid ξ ∈ [0, 1] with N_x points (center=0, edge=1):
- `x_f(ξ, t)`: functional zone fraction (primary state)
- `φ_tissue(ξ, t)`: tissue volume fraction (secondary state, V2.1)

Derived:
- `φ_v_f(ξ) = 1 - φ_f / x_f(ξ)`: local void in functional zone
- `φ_v_i(ξ) = 1 - φ_i / (1 - x_f(ξ))`: local void in inert zone
- `K(ξ)`: Kozeny-Carman permeability per grid point

### Governing equations

```
∂x_f/∂t = -x_f · (σ_cell(ξ,t) - σ_resist(ξ,t)) / η_eff  +  D_eff · ∂²x_f/∂ξ²
                    ↑ compaction                                  ↑ stress diffusion

σ_cell(ξ,t)   = n_cell · F_mc · f_bridge(t) · maturity(t) · ramp(t) · neighbor_factor(ξ)
σ_resist(ξ,t) = σ_0 · max(0, φ_f/x_f(ξ)/φ_RCP - 1)^α
```

BCs: zero-flux at ξ=0 (symmetry) and ξ=1 (domain edge).

### What's new vs parameter_sweep.py
The 1D PDE already exists inside `run_sweep_vectorised()` (lines 390-503 of parameter_sweep.py) but is:
- Embedded in a 200K-sample LHS sweep function
- Not callable as a standalone model
- Not fittable to DEM data
- Not plottable independently

The new `SpatialPDE` class will:
1. **Extract** the PDE into a clean standalone class (like `CompactionModel`)
2. **Add initialization from DEM snapshots** — bin granule positions into radial shells to get x_f(ξ, t=0) from actual packing, not just uniform
3. **Add fitting** — fit η_eff, σ_0, α to DEM spatial profiles (not just domain-averaged x_f)
4. **Add spatial plotting** — kymograph of x_f(ξ, t), radial profiles at key times, comparison to confocal data
5. **Add 2D extension** — optional 2D grid (N_x × N_y) for non-radially-symmetric scenarios
6. **Expose spatial profiles** for feeding into the contact network model

### Class interface

```python
class SpatialPDE:
    """1D/2D spatially-resolved compaction model."""

    def __init__(self, phi_f, phi_i, R_func, E_func, n_cells, ...,
                 N_x=20, geometry='radial'):
        ...

    @classmethod
    def from_params(cls, p: Params) -> 'SpatialPDE':
        """Construct from simulation Params."""

        """Initialize spatial profile from DEM snapshot (bin granules)."""

        """Load DEM output, fit, return (model, fit_result, data)."""

    def solve(self, t_span, eta_eff, sigma_0, alpha) -> dict:
        """Integrate PDE. Returns dict with x_f(xi,t), phi_v(xi,t), K(xi,t)."""

    def spatial_profile(self, t) -> dict:
        """Return spatial profiles at time t."""

    def descriptors(self, t) -> dict:
        """Compute 18 tissue descriptors from spatial state at time t."""
```

## Model 2: Contact Network (`analysis/contact_network.py`)

### What it captures
- Coordination number evolution Z(t) and distribution P(Z)
- Bridge percolation threshold (when does a spanning cluster of bridges form?)
- Force chain statistics (magnitude distribution, spatial alignment, chain length)
- Cluster size distribution (functional granule clusters connected by bridges)
- Connectivity metrics (graph diameter, betweenness centrality of bridges)
- Stochastic variation across realizations (Monte Carlo ensembles)

### Graph structure

```
G = (V, E)

Nodes V (one per granule):
  - type: functional (0) or inert (1)
  - radius: R_i
  - position: (x, y, [z])  — from DEM or random packing
  - n_cells: cells on this granule
  - fa_maturity: focal adhesion maturity (time-dependent)
  - bridge_count: number of active bridges emanating from this node
  - state: {active, exhausted} (exhausted = all cells senescent)

Edges E (one per contact or near-neighbor pair):
  - type: FF (func-func), FI (func-inert), II (inert-inert)
  - distance: center-to-center distance
  - overlap: max(0, R_i + R_j - d_ij)  — positive = contact
  - gap: max(0, d_ij - R_i - R_j)  — positive = separated
  - bridge_state: {none, forming, active, locked, broken}
  - bridge_force: force transmitted through bridge (nN)
  - bridge_age: time since bridge formed (h)
  - contact_force: Hertz contact force (nN)
```

### Evolution rules

Each timestep Δt:

1. **FA maturity update** (per node):
   ```
   maturity_i(t) = 1 - exp(-fa_rate · max(0, t - t_spread))
   ```

2. **Bridge formation** (per FF edge within sensing distance):
   ```
   P_bridge = 1 - exp(-rate · Δt · maturity · path_factor)
   path_factor depends on gap classification:
     - contact (overlap > 0): bridge_contact_factor (5.0)
     - void (gap < sense_dist): exp(-gap / bridge_decay_length)
     - inert-blocked: bridge_inert_factor (0.1)
   ```
   Check exclusion zone (angular separation from existing bridges).

3. **Bridge state machine**:
   ```
   none → forming (Poisson roll succeeds)
   forming → active (after bridge_formation_time)
   active → locked (force > bridge_lock_force_threshold)
   active → broken (gap > bridge_break_gap)
   active → senescent (after bridge_senescence_time, unless locked)
   ```

4. **Force balance** (sparse linear system on graph):
   ```
   For each node i:
     F_i = Σ_j [F_contact(overlap_ij) · n_ij + F_bridge(bridge_ij) · n_ij]

   Overdamped: v_i = F_i / γ_i
   dx_i = v_i · Δt  (with velocity cap)
   ```
   Contact force: Hertz (spheres only — no superellipsoid solver needed).
   Bridge force: Motor-clutch, ramped by bridge age, modulated by alignment.

5. **Topology update**: Recompute neighbor list (cKDTree, cheap for spheres).

6. **Metrics**: Z(t), cluster analysis (scipy.sparse connected components), percolation check, force statistics.

### What it builds on
- `coarse_grain._get_contacts()`: Already extracts (ci, cj) contact pairs from snapshots
- `coarse_grain.compute_coordination()`: Already computes Z, Z_ff, Z_fi, Z_ii
- `viz/percolation.py`: Already checks spanning/percolation on fields
- `image_analysis.py`: cKDTree neighbor analysis

### Class interface

```python
class ContactNetwork:
    """Graph-based contact network model for granular scaffold."""

    def __init__(self, positions, radii, types, n_cells_per_node, p: Params):
        """Initialize from arrays."""

    @classmethod
    def from_snapshot(cls, snap, p: Params) -> 'ContactNetwork':
        """Build graph from DEM snapshot."""

    @classmethod
    def from_packing(cls, p: Params, seed=None) -> 'ContactNetwork':
        """Generate random sphere packing and build graph (no DEM needed)."""

    @classmethod
    def from_run(cls, run_dir) -> tuple:
        """Load DEM, build networks at each saved timepoint, return timeseries."""

    def step(self, dt, t):
        """Advance one timestep: bridges, forces, positions, topology."""

    def solve(self, t_span, dt=0.5) -> dict:
        """Integrate forward. Returns timeseries of metrics."""

    def metrics(self) -> dict:
        """Current snapshot metrics: Z, clusters, percolation, forces."""

    def descriptors(self) -> dict:
        """18 tissue descriptors from current graph state."""

    def adjacency_matrix(self, edge_type='all') -> scipy.sparse.csr_matrix:
        """Sparse adjacency matrix (optionally filtered by edge type)."""
```

## Cross-Feeding Protocol

### PDE → Network
The spatial PDE produces local packing fraction φ_f(ξ). This maps to an expected local coordination number:
```
Z_expected(ξ) = Z_iso + c_Z · max(0, φ_f(ξ)/x_f(ξ) - φ_RCP)^0.5
```
where Z_iso ≈ 4 (isostatic for 2D frictionless). This informs the graph model's edge creation probability in each spatial region.

### Network → PDE
The graph model produces:
- **Bridge percolation state**: binary flag → if percolated, PDE's effective cell stress gets a boost (coordinated contraction)
- **Mean coordination Z(t)**: feeds into PDE's η_eff (more contacts → higher viscosity → slower compaction)
- **Force chain alignment**: anisotropic effective viscosity (if desired in 2D extension)

### Joint descriptor computation
Both models produce inputs to the 18 tissue descriptors:
- PDE: BV/TV, porosity, permeability, pore size, anisotropy (from spatial profiles)
- Network: connectivity, coordination number, surface density (from graph topology)
- Combined: merge into full descriptor vector → organ distance via `arch_distance.py`

## Validation Strategy

1. **Consistency check**: Run DEM, then initialize both mesoscale models from the same DEM packing. Compare their outputs to DEM ground truth.
2. **Standalone check**: Initialize both models from Params alone (no DEM). Compare to mean-field ODE predictions (should agree when spatial gradients are small).
3. **Cross-model check**: Run PDE and Network independently, then with cross-feeding. Check that cross-feeding improves agreement with DEM.
4. **Experimental comparison**: Compare PDE radial profiles to confocal porosity profiles. Compare Network connectivity to confocal contact analysis.
