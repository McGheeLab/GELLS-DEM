# V2.4: Rebuild 2D Visualization System (`viz2/`)

## Context

The current visualization in `viz/` was built incrementally across V1.x–V2.3. It's scattered across 12+ files with duplicated drawing code, inconsistent data access patterns, and missing key analyses (Voronoi shrink-wrap, per-mode energy spatial maps, proper percolation theory). The user wants a clean, unified V2 viz system built from the scaffold map foundation, with Voronoi-based spatial analysis, full energy decomposition, and void percolation.

## File Layout

```
viz2/
├── __init__.py              # Package init, exports run_all
├── common.py                # Shared: colors, drawing helpers, data utilities
├── voronoi.py               # Voronoi engine: center-based + boundary shrink-wrap
├── scaffold_map.py          # Module 1: Vector-drawn scaffold map (foundation)
├── voronoi_shapes.py        # Module 2: Voronoi shape factors + overlay
├── phase_fractions.py       # Module 3: Global + local phase fractions
├── movies.py                # Module 4: GIF animations of all temporal evolutions
├── energy_stress.py         # Module 5: Stress/strain + 6 energy mode spatial maps
├── void_percolation.py      # Module 6: Void percolation theory
└── postprocess.py           # Orchestrator entry point (CLI + programmatic)
```

## Module Designs

### 1. `common.py` — Shared Utilities

Centralizes repeated code currently duplicated across `viz/postprocess.py`, `viz/cells.py`, `viz/stress.py`:

- **Color constants**: `FUNC_COLOR='#CC2222'`, `INERT_COLOR='#22AA22'`, `VOID_COLOR='#000000'`, `CELL_COLORS` dict, `CELL_LABELS` dict
- `load_data(run_dir)` → `(hist, snaps, p, metadata)` — wraps `new_dem_0.load_run()`
- `select_indices(n, indices, n_panels=5)` — evenly-spaced snapshot picker
- `draw_granule_patches(ax, snap, p, colors=None)` — superellipse/circle patches with per-gtype coloring
- `draw_cells_on_ax(ax, snap, p)` — cell overlay (bridges as ellipses, others as circles)
- `cell_world_positions(snap)` → `(wx, wy)` — compute cell positions from granule + local angle. Extracted from `viz/cells.py:_cell_world_positions()`
- `setup_scaffold_axes(ax, p, dark=True)` — configure axes limits, aspect, background
- `ensure_phase_fields(snap, p)` — render phi_f/phi_i/phi_v if not in snapshot, using `render_fields()` or reconstructing a minimal GranuleSystem

### 2. `voronoi.py` — Voronoi Tessellation Engine

Computational core shared by modules 2 and 3. Two tessellation modes:

**Center-based** (`voronoi_from_centers(snap, p)`):
- Seeds = functional granule centers (x[i], y[i]) for gtype==0
- `scipy.spatial.Voronoi` with mirror-image guard points at domain boundaries
- Returns `vor` object + `cell_granule_map` + clipped polygons

**Boundary-based shrink-wrap** (`voronoi_from_boundaries(snap, p, n_pts=32)`):
- Seeds = `n_pts` points sampled on each functional granule's superellipse boundary via `superellipse_polygon_pts()`
- Guard points along domain edges at granule-diameter spacing
- `scipy.spatial.Voronoi` on all seed + guard points
- Merge sub-cells per granule via `ConvexHull` of all sub-region vertices
- Clip to domain [0,Lx]×[0,Ly] via Sutherland-Hodgman algorithm (pure numpy, no shapely dependency)

**Utilities**:
- `clip_polygon_to_rect(verts, xmin, ymin, xmax, ymax)` — Sutherland-Hodgman clipping
- `polygon_area(verts)` — shoelace formula
- `polygon_centroid(verts)` — centroid from vertices
- `compute_shape_factors(polygons)` → dict per region: area, perimeter, circularity (4πA/P²), aspect_ratio (PCA), elongation
- `compute_local_phase_fractions(snap, p, polygons, Ngrid=200)` → local phi_f/phi_i/phi_v per Voronoi cell, using point-in-polygon on phase field grid via `matplotlib.path.Path.contains_points()`

**Reuse**: `analysis/volume_conservation.py:voronoi_compartments()` for the cKDTree nearest-granule approach (used for validation / fast mode)

### 3. `scaffold_map.py` — Module 1: Foundation Scaffold Map

Refactored from `viz/postprocess.py:plot_scaffold_map()` (lines 243–448), using `common.py`:

- `plot_scaffold_map(snaps, hist, p, indices=None, outdir=None)` — multi-panel at selected times
- `plot_scaffold_map_single(snap, p, t=0.0, ax=None)` → `ax` — single-frame for movies/composites
- Black background = void, red patches = functional, green = inert
- Cell bridges in crimson (their standard color) but counted as functional in data analysis
- Per the user request: bridge space contributes to functional phase fraction in analysis

### 4. `voronoi_shapes.py` — Module 2: Voronoi Shape Factors

### 5. `phase_fractions.py` — Module 3: Global + Local Phase Fractions

- `gif_voronoi(snaps, hist, p, outdir, fps=4)` → voronoi_evolution.gif

### 7. `energy_stress.py` — Module 5: Energy & Stress/Strain Maps

**Stress/Strain** (reuse `analysis/coarse_grain.py`):
- `plot_stress_maps(snaps, hist, p, outdir=None)` — pressure + von Mises spatial maps via `coarse_grain_field(snap, p, 'stress')`
- `plot_strain_maps(snaps, hist, p, outdir=None)` — volumetric + shear strain rate via `coarse_grain_field(snap, p, 'strain_rate')`

**6 Energy Mode Spatial Maps** — each computed on Ngrid×Ngrid grid with Gaussian coarse-graining (w = 1.5×mean_r):

| Mode | Source Data | Formula | Grid Placement |
|------|-----------|---------|---------------|
| Cell traction | cell_fx, cell_fy, cell positions | E = 0.5 × \|F_cell\| × bridge_length | Cell world position |
| Hertz/JKR contact | contact_overlap, F_normal, R_eff | E = (2/5)E*√R_eff × δ^(5/2) − W×π×a² | contact_cx, contact_cy |
| Granular friction | F_normal, A_contact, velocities | P = τ_0 × A_contact × tanh(\|v_t\|/v_ref) × \|v_t\| | Contact midpoint |
| Osmotic pressure | phi_v grid | Π = Π_0 × \|∇φ_v\|² / φ_v | Direct on grid |
| Inert frustration | F-I contacts (filtered by gtype) | E = F_normal × overlap (inert-functional only) | Contact point |
| Interfacial tension | phi_f, phi_i grids | E = γ × (\|∇φ_f\|² + \|∇φ_i\|²) | Direct on grid |

- `compute_energy_field(snap, p, mode, Ngrid=30)` → 2D array
- `plot_energy_modes(snaps, hist, p, outdir=None)` — 2×3 panel figure per timepoint
- `plot_energy_timeseries(snaps, hist, p, outdir=None)` — total per mode vs time
- `run_all(snaps, hist, p, outdir=None)`

### 8. `void_percolation.py` — Module 6: Void Percolation Theory

- `compute_void_clusters(phi_v, threshold=0.3)` → labels, n_clusters, sizes (uses `scipy.ndimage.label`)
- `detect_percolation(labels, axis)` → bool, spanning_cluster_id (checks if any cluster touches both edges)
- `cluster_size_distribution(labels)` → sizes, counts for P(s) analysis
- `fit_power_law(sizes, counts)` → exponent τ, R² (P(s) ~ s^-τ near critical)
- `plot_void_clusters(snaps, hist, p, outdir=None)` — labeled clusters colored by ID on scaffold map
- `plot_percolation_evolution(snaps, hist, p, outdir=None)` — percolation status, largest cluster fraction, cluster count vs time
- `plot_cluster_size_dist(snaps, hist, p, outdir=None)` — log-log P(s) with power-law fits
- `plot_kozeny_carman(hist, p, outdir=None)` — K(t) with percolation threshold annotation
- `run_all(snaps, hist, p, outdir=None)`

### 9. `postprocess.py` — Orchestrator

def run_all(run_dir=None, snaps=None, hist=None, p=None,
