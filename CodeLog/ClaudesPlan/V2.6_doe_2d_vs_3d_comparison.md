# V2.6: DOE 2D vs 3D Comparison Analysis

## Goal
Compare matched 2D and 3D DOE runs (same LHS design matrix, seed=2025, 20 runs each) to identify dimensional scaling relationships and determine which metrics are predictive from 2D simulations.

## Implementation

### New file: `viz/doe_2d_vs_3d.py`
7 analysis modules:
1. **Paired scatter plots** — 2D vs 3D final metrics with 1:1 line + OLS regression
2. **Dimensionless collapse** — normalize by φ_RCP(d), Z_iso(d), ε_RCP(d), K/d²
3. **Effect ranking comparison** — factor importance heatmap (Pearson r) in 2D vs 3D
4. **Time evolution overlay** — 2D (blue) vs 3D (red) mean trajectories ± σ
5. **Scaling regression table** — 3D = α + β·2D fit for each metric, R² bar chart
6. **Summary dashboard** — radar chart of mean responses
7. **3D/2D ratio vs factors** — parameter-dependent scaling detection

### Data Status
- 20 2D runs: all complete (49 data points, t=48h)
- 20 3D runs: 10 complete, 10 partial (reconstructed from snapshots via reconstruct_history.py)

### Key Findings
- **Permeability (K)** is the only metric with strong 2D→3D collapse (R²=0.94, slope=0.83)
  - Consistent with Kozeny-Carman being a geometric/statistical property
- **Functional connectivity**: 3D ≈ 4× higher than 2D (extra connectivity dimension), R²=0.22
  - The 3D/2D ratio decreases with functional ratio (r=-0.41), suggesting inert presence matters more in 3D
- **Active bridges**: 3D ≈ 140× more bridges — extra surface area and contacts dominate
- **Porosity, compaction ratio, solid fraction**: nearly identical 2D/3D (ratios ≈ 1.0) but low R²
  - These are set by the same φ_solid_target, so similarity is expected
- **Contact count**: 3D ≈ 51× more contacts — consistent with Z_3D/Z_2D ≈ 1.5 × more granules
- **Factor importance shifts**: stiffness (E_modulus) and R_inert more important in 3D for contacts/force;
  functional ratio remains important for connectivity in both
