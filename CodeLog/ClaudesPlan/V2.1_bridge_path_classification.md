# Plan: Path-Dependent Bridge Probability (Fibroblast Model)

## Context

Bridges form too easily — nearly every cell finds a bridge target. The current model uses a simple linear proximity decay (`1 - gap/sense_dist`) that doesn't distinguish between contact, void, and inert-blocked paths. Physically, a fibroblast extends filopodia from its granule surface to sense the environment:

- **Contact**: cells crawl directly between touching surfaces — highest probability
- **Void gap**: filopodia must probe empty space — probability decays exponentially with gap distance (characteristic filopodia reach ~10 µm)
- **Inert-blocked**: filopodia hit inert material they can't attach to — further reduced

## Probability Model

Replace the current linear `proximity = 1 - gap/sense_dist` with a physically-motivated model:

```
p_bridge = (1 - exp(-rate * dt)) * path_factor

where path_factor =
  contact (gap ≤ 0):       bridge_contact_factor                          (e.g. 5.0)
  void (gap > 0):           exp(-gap / bridge_decay_length)                (exponential decay)
  inert-blocked (gap > 0):  bridge_inert_factor * exp(-gap / bridge_decay_length)
```

The exponential decay naturally captures filopodia reach:
- gap = 0 µm: factor = 1.0 (touching but not overlapping)
- gap = 10 µm: factor ≈ 0.37 (one decay length — moderate)
- gap = 30 µm: factor ≈ 0.05 (three decay lengths — unlikely)
- gap = 50 µm: factor ≈ 0.007 (five decay lengths — rare)

`cell_sense_distance` remains the hard cutoff (zero probability beyond it).

## New Parameters in `Params`

```python
bridge_contact_factor: float = 5.0       # probability boost at direct granule contact
bridge_decay_length: float = 10.0        # µm, characteristic filopodia reach (void decay)
bridge_inert_factor: float = 0.1         # additional penalty when inert blocks path
```

## Implementation

### 1. `_classify_bridge_path(gs, p, gi, gj, pos_i, pos_j)` — new function

Vectorized ray-cast between gi and gj centers:
1. If gap ≤ 0 → return `bridge_contact_factor`
2. Cast ray, check all N granules for bounding-sphere intersection
3. If inert granule intersects → return `bridge_inert_factor * exp(-gap / bridge_decay_length)`
4. Otherwise (void) → return `exp(-gap / bridge_decay_length)`

Handles periodic BCs via minimum-image displacement. Fully vectorized (no Python per-granule loop).

### 2. Modify `_attempt_new_bridges()` (~line 2613)

- Add `path_factor=1.0` parameter
- Replace `proximity` with `path_factor`:
  ```python
  # OLD:
  proximity = 1.0 - gap / p.cell_sense_distance
  p_bridge = (1.0 - np.exp(-rate * p.dt)) * proximity

  # NEW:
  p_bridge = (1.0 - np.exp(-rate * p.dt)) * path_factor
  ```

### 3. Modify 4 call sites in force loops

Files: `new_dem_0.py` lines ~2788, ~2903, ~3098, ~3196

- **Service**: Remove `gap > L_rest` gate → always service committed bridges
- **Attempt**: Change condition to `gap < cell_sense_distance`, compute `path_factor`, pass it through

```python
# Before:
if gap > p.L_rest:
    _service_committed_bridges(...)
if 0 < gap < p.cell_sense_distance and gap > p.L_rest:
    _attempt_new_bridges(...)

# After:
_service_committed_bridges(...)
if gap < p.cell_sense_distance:
    path_factor = _classify_bridge_path(gs, p, i, j, pos_i, pos_j)
    _attempt_new_bridges(..., path_factor=path_factor)
```
