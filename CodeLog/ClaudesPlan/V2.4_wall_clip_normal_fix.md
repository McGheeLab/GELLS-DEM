# V2.4 Bug Fix: Wall Contact Clip Normal Inversion

## Problem

When rendering phase fields (phi_f, phi_i, phi_v), wall-adjacent particles displayed
spurious void patches. The JKR contact clip planes for wall contacts had **inverted
normals**, clipping the domain-facing side of the particle instead of the wall-facing side.

### Root Cause

The wall clip normals reused the force `sign` variable, which points INTO the domain
(the direction of wall repulsion force). But the clip convention requires the normal to
point TOWARD the wall (from the particle toward the other object), matching the
inter-particle clip convention where `n` points from particle `i` toward contact partner `j`.

**Before (incorrect):**
```python
nx_w = float(sign)     # points INTO domain — clips domain-facing side
```

**After (correct):**
```python
nx_w = -float(sign)    # points TOWARD wall — clips wall-facing side
```

### Effect of the Bug

For a particle at x=30 with R=40 near the left wall (x=0):
- Incorrect clip: removes material for X > 60 (domain-side sliver)
- Correct clip: removes material for X < 0 (material inside the wall)

Corner particles (near two walls) were worst affected: two intersecting wrong-direction
clips created rectangular void patches in the particle interior, visible as randomly
distributed rectangular void artifacts in the rendered fields.

### Impact on Analysis

The clip-affected phi fields are used for ALL scalar metrics (connectivity, porosity,
tissue fraction, packing in functional-rich zone, etc.). With `boundary_exclusion=0.2`,
the inner-region metrics were partially protected (affected particles mostly fall within
the exclusion zone), but the rendered fields and any full-domain analysis were affected.

## Changes

1. **`compute_forces()` — 2D circle wall clips** (line ~3584): `float(sign)` → `-float(sign)`
2. **`compute_forces()` — 2D superellipse wall clips** (line ~3610): `float(wall_sign)` → `-float(wall_sign)`
3. **`compute_forces_3d()` — 3D sphere wall clips** (line ~3883): `float(sign)` → `-float(sign)`
4. **`compute_forces_3d()` — 3D superellipsoid wall clips** (line ~3899): `float(sign)` → `-float(sign)`

## Verification

After the fix, wall clips correctly remove only the portion of the particle that extends
beyond the wall boundary. The clip equation for a left wall (x=0) becomes:
```
plane = (X - cx) * (-1) - |cx| = -X
```
Which clips at X=0 (the wall face), as intended.
