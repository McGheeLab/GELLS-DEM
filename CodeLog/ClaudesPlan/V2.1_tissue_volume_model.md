# Plan: V2.1 — Tissue Volume Tracking in Mean-Field Model

## Context

Currently cells are modeled as force generators that don't occupy volume. `n_cells_per_func`
affects compaction force but has **zero effect on architecture descriptors** (BV/TV, porosity,
permeability). In reality:
1. Cells adhered to functional granules form a tissue shell, occupying void space
2. Bridges between granules create scaffolding for more cells to migrate into the gap
3. The inter-granular space progressively fills with cells + ECM → becomes tissue-like
4. This changes effective BV/TV, porosity, permeability, and pore radius

## Approach: Logistic Tissue ODE Alongside Existing Compaction PDE

Add `phi_tissue(xi, t)` — a spatially-resolved tissue volume fraction that grows within
the functional zone, driven by cell count, FA maturity, and bridge formation. Tissue fills
available void space logistically. **No feedback into compaction mechanics** (tissue is soft).
Corrected architecture descriptors flow into organ distance computation.

### New State Variable

`phi_tissue(xi, t)` on the same N_x=20 radial grid, shape `(n, N_x)`.

### Growth ODE (per grid point)

```
d(phi_tissue)/dt = k_tissue × min(1, n_cells/n_ref) × maturity(t)
                   × max(alpha_0, f_bridge(t) × neighbor_factor(xi))
                   × max(0, alpha_fill × phi_void_func(xi,t) − phi_tissue)
```

- **k_tissue = 0.05 h⁻¹** — base tissue formation rate
- **alpha_fill = 0.6** — max fraction of void that tissue can fill (rest = perfusive channels)
- **alpha_0 = 0.1** — minimum growth even without bridges (surface cells only)
- **n_ref = 10** — reference cell count for normalization
- **maturity** and **f_bridge** — already computed in the compaction loop, reused here
- **neighbor_factor(xi)** — more tissue at center (more neighbors/bridges), less at edge

IC: `phi_tissue(xi, 0) = 0` (no tissue at start)

### Corrected Architecture Descriptors

```
phi_tissue_global = mean(x_f) × mean(phi_tissue)
BV_TV_eff         = phi_f + phi_tissue_global          (granules + tissue)
porosity_eff      = 1 − BV_TV_eff
eps_f_tissue      = max(0, phi_v_f_local − phi_tissue)  (tissue-reduced void)
K_f_tissue        = eps_f³ × d_f² / (180 × (1−eps_f)²) (Kozeny-Carman with tissue)
```

Organ distance computation uses these tissue-corrected values instead of raw granule fractions.

## Physical Implications

- **n_cells_per_func now matters for architecture**: More cells → faster tissue growth →
  higher BV_TV_eff, lower porosity_eff, lower permeability
- **Dense organs (cardiac, liver)**: May match better because tissue adds to BV/TV
- **Porous organs (lung, bone)**: Tissue reduces porosity, may match worse unless
  few cells are used (low n_cells, low func_ratio)
- **Bridge fraction is key**: Without bridges (early times, edge of scaffold), tissue
  growth is limited to alpha_0 fraction → spatial heterogeneity

## Verification

1. `k_tissue=0`: all tissue outputs should be zero, organ distances identical to V1.12
2. `n_cells=0`: tissue should be zero (n_cells_norm = 0 kills growth)
3. `alpha_fill=0`: tissue should be zero
4. Final phi_tissue ≤ alpha_fill × phi_void_func (clamped, never overfills)
5. BV_TV_eff ≥ phi_f always (tissue can only add, not subtract)
6. Permeability with tissue ≤ permeability without tissue (tissue reduces void for flow)
7. Spatial profile: more tissue at center (xi=0) than edge (xi=1) due to neighbor_factor
8. Run sweep and verify organ ranking changes make physical sense

- `phi_tissue` array: `(200K, 20)` = 32 MB additional
- Per-step ODE: element-wise numpy, ~30% overhead in PDE loop
- No CFL concern (logistic ODE, not PDE — unconditionally stable with dt=0.5h, k=0.05)
