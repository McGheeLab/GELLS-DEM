# V2.4: Extend viz2/ to Support 3D Analysis

## Context

The viz2/ package (10 files) was built for 2D simulation data. The DOE includes 3D runs (e.g. DOE_3D_0001: 433 granules, 4644 cells, 200^3 phase fields, Lz=120 um thin slab, periodic BCs). This plan extends viz2/ so the same `postprocess.py` pipeline works transparently on both 2D and 3D data.

**Strategy: Hybrid** — most modules extend in-place with a z-midplane slicing approach (3D fields -> 2D slice for matplotlib display). One new file `scaffold_map_3d.py` for PyVista-based 3D rendering.

## Implementation Summary

### Core Infrastructure: `common.py` Additions

New helpers added:
- `is_3d(snap, p)` — detect 3D mode from `p.mode` or `snap['z']`
- `slice_field_z_midplane(field_3d, z_frac=0.5)` — extract 2D slice from (Ng,Ng,Ng) -> (Ng,Ng)
- `slice_snap_z_midplane(snap, p, z_frac=0.5)` — filter granules near z=Lz/2, project to 2D snap with cross-section radii `a_eff = a * (1 - (dz/c)^n2)^(1/n2)`, yaw from quaternion, remapped cell/contact arrays
- `cell_world_positions_3d(snap)` — (wx,wy,wz) via `superellipsoid_point` + `quat_rotate`
- Extended `ensure_phase_fields()` — handles 3D via `render_fields_3d`, builds GranuleSystem with z, c, n2, quat

### Per-Module Changes

| Module | Change Type | Key Mechanism |
|--------|------------|---------------|
| `scaffold_map.py` | Extended | `slice_snap_z_midplane` + z-label annotation |
| `voronoi_shapes.py` | Extended | `slice_snap_z_midplane` for all 4 plot functions |
| `phase_fractions.py` | Extended | `slice_field_z_midplane` + `slice_snap_z_midplane` for local heatmaps/timeseries |
| `energy_stress.py` | Extended | z-midplane slice of `coarse_grain_field` 3D results; `compute_energy_field` uses sliced snap |
| `void_percolation.py` | Extended | `detect_percolation` generalized to N-d; `plot_void_clusters` uses z-slice for display, full 3D for stats |
| `movies.py` | Extended | All GIF functions detect `is_3d` and z-slice per frame |
| `scaffold_map_3d.py` | **NEW** | PyVista off-screen rendering: superellipsoid meshes, cell spheres, bridge tubes, z-clip |
| `postprocess.py` | Extended | Registered `scaffold_3d` module |

### New File: `scaffold_map_3d.py`

PyVista-based 3D scaffold visualization:
- `_granule_mesh(snap, gi)` — watertight superellipsoid mesh (parametric grid + poles)
- `render_snapshot_3d(snap, p)` — off-screen render with z-clip, cells, bridges
- `plot_scaffold_3d(snaps, hist, p)` — multi-panel composite in matplotlib
- `run_all()` — silently skips if 2D or no PyVista
