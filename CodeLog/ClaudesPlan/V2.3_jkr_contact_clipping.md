# V2.3: JKR Contact Model + Contact-Face Clipping (COMPLETED 2026-03-16)

## Context

The `test_hertz_clipping.py` demo proved that JKR (Johnson-Kendall-Roberts) contact
with half-plane rendering clipping produces physically realistic deformation of soft
hydrogel granules under compression. The main GELS code still uses Hertz + DMT
adhesion and rigid-shape rendering, which produces unrealistic overlapping circles
instead of flattened contact faces.

**Why JKR, not DMT?** For soft hydrogels (E ~ 1 kPa, W ~ 0.001–0.02 J/m²), the
Tabor parameter μ_T = (R W² / E*² z₀³)^{1/3} >> 1, placing us firmly in the JKR
regime. DMT is only valid for μ_T << 1 (hard, low-adhesion contacts). JKR gives a
larger contact patch due to adhesion pulling surfaces together, which is the dominant
physics for our system.

**Backwards compatibility**: JKR reduces exactly to Hertz when W_adhesion = 0:
- δ = a²/R* → a = √(R*δ)
- F = (4/3)E*a³/R* = (4/3)E*√R*δ^{3/2} (pure Hertz)

So replacing Hertz+DMT with JKR is a strict superset with zero breakage.

**Branch**: Version-2.3 (current, extends existing LS-DEM work)

## Implementation Phases

### Phase A: JKR Force Model (DONE)

**Goal**: Replace Hertz+DMT with JKR everywhere in the force computation.

**New functions** (add after `hertz_contact_force`, ~line 663):

| Function | Purpose |
|----------|---------|
| `jkr_force_from_overlap(delta, R_eff, E_star, W)` | Given overlap δ, solve for contact radius a via Newton-Raphson, return (F, a) |
| `jkr_contact_radius(F_ext, R_eff, E_star, W)` | Contact radius from applied force (analytical) |
| `jkr_pulloff_force(R_eff, W)` | Pull-off force: F_po = (3/2)πWR* |

**Unit convention** (matching existing code):
- E_star [Pa], R_eff [µm], delta [µm], W [J/m²]
- Returns F [nN], a [µm]
- Conversion: E*_sim = E*_Pa × 1e-3 [nN/µm²], W_sim = W [nN/µm] (1 J/m² = 1 nN/µm)

**Changes to `compute_forces()` (2D rigid path, ~line 2639)**:
```
BEFORE:  Fc = hertz_contact_force(E_star, R_eff, overlap)
         F_adh = 2π W R* × 1e3
         F_normal = Fc - F_adh

AFTER:   F_normal, a_contact = jkr_force_from_overlap(overlap, R_eff, E_star, W)
```

Same pattern in `compute_forces_3d()` (~line 2900).

**Wall contacts** (~line 2729 2D, ~line 2979 3D):
```
BEFORE:  Fw = hertz_contact_force(E_star_gw, r, pen)

AFTER:   Fw, a_wall = jkr_force_from_overlap(pen, r, E_star_gw, W_wall)
```
Wall R_eff = R (flat surface, as in demo). W_wall = W_adh for the granule type.

**Contact dict update**: Add `'a_contact'` key with the JKR contact radius.

### Phase B: Contact Clip Storage (DONE)

**Goal**: Track per-particle contact-face clip planes for rendering.

**New GranuleSystem field** (add in `__init__`, ~line 350):
```python
self.contact_clips = None  # set to [[] for _ in range(N)] each timestep
```

**Populated during force computation** (after JKR gives F, a):
```python
clip_d = np.sqrt(max(R_i**2 - a_contact**2, 0.01))  # distance from center to flat face
gs.contact_clips[i].append((nx, ny, clip_d))     # contact normal, clip distance
gs.contact_clips[j].append((-nx, -ny, clip_d))   # opposite normal for j
```

For **wall contacts**: `clip_d = distance_from_center_to_wall` (as in demo).

**Reset each timestep**: Clear `gs.contact_clips` at the top of `step()`.

### Phase C: Clipped Rendering (DONE)

**Goal**: All render functions apply half-plane clipping at contact faces.

**Algorithm** (from JKR demo, proven to work):
For each grid point in the bounding box of particle i:
1. Compute base SDF (circle, superellipse, or deformed pull-back)
2. For each contact clip (nx, ny, clip_d) on particle i:
   `plane_sdf = (dx * nx + dy * ny) - clip_d`
   `sdf = max(sdf, plane_sdf)`
3. Evaluate tanh profile from the clipped SDF

**Functions to modify**:
- `_stamp_circle_2d()`: add clips parameter, apply max with half-planes
- `_stamp_superellipse_2d()`: same
- `_stamp_deformed_2d()`: apply clips after semi-Lagrangian pull-back
- `_stamp_granule_3d()`: 3D version with (nx, ny, nz, clip_d)
- `_stamp_deformed_3d()`: 3D deformed + clips

**Signature change**:
```python
def _stamp_circle_2d(X, Y, cx, cy, r_eff_i, w, phi_f, phi_i, gtype, clips=None):
```
When `clips` is None or empty, behaviour is identical to current (no clipping).

### Phase D: LS-DEM Adhesion (DONE — revised)

**Goal**: Add adhesive forces to the LS-DEM deformable contact path.

**Original approach (reverted)**: Applied adhesion at the surface-node level inside
`lsdem.py`. This drove deformation DOFs (F_eps) via ~20 near-surface nodes per contact,
causing violent deformation (ε saturated at cap = 0.42). Root cause: adhesion forces on
nodes outside the contact zone produced ~3,140 nN·µm of generalized force per pair.

**Corrected approach**: Adhesion applied as a translational-only JKR correction in
`compute_forces()` / `compute_forces_3d()` at the pair level:
```python
# After LS-DEM gives pure repulsive F_i, F_j, F_eps_i, F_eps_j:
F_jkr, a_contact = jkr_force_from_overlap(overlap, R_eff, E_star, W_adh)
F_hertz = hertz_contact_force(E_star, R_eff, overlap)
F_adh_correction = F_jkr - F_hertz  # negative = attractive
F[i] += F_adh_correction * n_hat   # translational only
F[j] -= F_adh_correction * n_hat   # does NOT enter F_eps
```

This ensures:
- LS-DEM surface nodes compute pure repulsive penalty → physically correct deformation
- JKR adhesion pulls particles together but doesn't drive modal deformation
- Deformation strains are 1–3% (physically reasonable for soft hydrogel contacts)

**LS-DEM contact radius**: For rendering clips, `jkr_force_from_overlap` returns `a_contact`
directly when adhesion is present; falls back to `√(R*·δ)` otherwise.
