# V2.3: Multi-Stage Bridge Formation (Cell Spatial Awareness)

## Context

Bridge formation previously collapsed sensing, migration, and contraction into a single
stochastic event -- a cell instantly transitioned from PROLIFERATING to BRIDGING and began
pulling. This is unphysical: real fibroblasts must (1) sense a target via filopodia,
(2) crawl across their host granule surface toward the contact point, (3) extend across
the gap, and (4) contract. Additionally, cells on the far side of a granule could bridge
to targets on the opposite side, and probability decayed from granule center rather than
cell centroid.

## Design: New MIGRATING State

Added a `MIGRATING` state (value 5) to the cell lifecycle:

```
PROLIFERATING -> (probability check + hemisphere filter) -> MIGRATING -> (directed crawl) -> BRIDGING -> (force ramp) -> mature bridge
```

### MIGRATING state behavior:
- Cell has identified a target granule (`cell_bridge_target` set)
- Cell crawls on host granule surface **toward** the target-facing contact point
- Directed speed = `cell_migration_speed x bridge_directed_speed_mult` (default 2x)
- Once angular position is within `bridge_commit_angle` (~29 deg) of contact azimuth -> BRIDGING
- If target leaves sensing range -> revert to PROLIFERATING (abandon attempt)
- **No bridge force** during MIGRATING (cell is crawling on its own granule, not spanning gap)
- Fast-path: cells already at the contact point skip MIGRATING and go straight to BRIDGING

### Cell spatial awareness:
- **Hemisphere check**: `np.dot(cell_offset, d_to_tgt) < 0` -> skip. Only cells on the
  target-facing hemisphere can attempt bridges.
- **Cell-specific gap**: Gap measured from cell world position to target granule surface,
  not from granule center.
- **Cell-specific decay**: Probability decays from cell centroid position, replacing the
  old granule-center-based decay.

### Timescale estimate:
- Hemisphere-filtered cells are 0-90 deg from contact, average ~45 deg
- Arc distance at 45 deg on R=40 um: 31 um
- At 2x directed speed (10 um/h): ~3h migration + 2h force ramp = ~5h total
- Cells closer to contact (higher probability due to existing decay) bridge faster

### New parameters:
- `bridge_commit_angle: float = 0.5` -- radians (~29 deg), arrival threshold
- `bridge_directed_speed_mult: float = 2.0` -- directed crawl speed multiplier

## Implementation

### Files modified:
- `new_dem_0.py` -- CellState enum, Params, bridge functions, cell update, metrics
- `viz/cells.py` -- color/label for MIGRATING state
- `CLAUDE.md` -- documented new state and params
- `CodeLog/Updates/CHANGELOG.md` -- V2.3 entry

### Changes:

1. **CellState enum**: Added `MIGRATING = 5` (backward compatible)
2. **Params**: Added `bridge_commit_angle` and `bridge_directed_speed_mult`
3. **Helper functions** (new, near line ~2585):
   - `_cell_world_pos_2d(gs, ci)` -- world (x,y) from parametric surface angle
   - `_cell_world_pos_3d(gs, ci)` -- world (x,y,z) via superellipsoid_point + quat rotation
   - `_compute_gap(gs, gi, tgt, p)` -- surface-to-surface gap, handles periodic BCs
   - `_angular_distance_to_target_2d(gs, ci, tgt, p)` -- angular distance in body frame
   - `_angular_distance_to_target_3d(gs, ci, tgt, p)` -- great-circle distance on parametric sphere
4. **`_attempt_new_bridges`**: Major rewrite with hemisphere filter, cell-specific decay,
   MIGRATING vs BRIDGING decision based on angular distance to contact
5. **`_update_individual_cells`**: New MIGRATING handler with abandonment, arrival check,
   and directed arc stepping (2D) / slerp (3D)
6. **Metrics**: Added `n_migrating_cells` to timeseries
7. **Viz**: Royal blue (#4169E1) for MIGRATING cells

## Verification (completed 2026-03-16)

Ran 12h 2D deformable trial (`results/test_migrating_bridges/`):
- MIGRATING cells appear in early timesteps (visible as royal blue diamonds)
- Bridge count builds gradually: 0 at t=0, 8 at t=2h, 18 at t=4h, 41 at t=12h
- Deformation physically reasonable: max |eps| ~10%, mean ~5% (vs 42% cap before fix)
- Cell state transitions visible: PROLIFERATING -> MIGRATING -> BRIDGING -> SENESCENT
- Bridge turnover observed (some bridges break, new ones form)
