# V2.3: Variational LS-DEM (Henzel & Karapiperis 2026)

## Context

GELS currently models granules as rigid superellipsoids with Hertzian contact.
V2.2 added MC-DEM to correct for multi-contact stiffening, but particles still can't
deform. For soft hydrogels at high packing fractions (phi > 0.65), granules physically
flatten at contacts, change shape, and form new contacts as they spread. This is the
dominant physics missing from the current model.

The Henzel & Karapiperis 2026 variational LS-DEM method extends rigid DEM to deformable
particles by adding per-particle scalar deformation DOFs that modulate pre-defined spatial
mode shapes. Each particle's geometry is tracked via a signed distance field (SDF).
Contact detection replaces Newton-Raphson with surface-node queries into neighbouring
particles' SDFs, yielding multi-point contact patches.

**Critical simplification**: GELS is overdamped (no inertia). The paper's second-order
deformation equation `M ε̈ + K ε = F_ε` reduces to first-order:
`γ_def dε/dt + K ε = F_ε`, which is vastly simpler to implement and integrate.

**Branch**: Version-2.3 (current)

---

## Architecture Overview

### New Module: `lsdem.py`

All LS-DEM functions live in a new file to keep `new_dem_0.py` manageable. The main
engine imports from `lsdem` only when `deformable_enabled=True`.

### Key Concepts

1. **SDF grids**: Pre-computed signed distance field per particle on a local body-frame grid
2. **Surface nodes**: Discrete probe points on each particle's surface for contact detection
3. **Deformation modes**: Fixed spatial mode shapes Φ_α(x) with time-varying amplitudes ε_α(t)
4. **Semi-Lagrangian update**: Deformed SDF evaluated on-demand via inverse displacement mapping
5. **Implicit Euler**: Unconditionally stable integration of overdamped deformation DOFs

**Contact detection algorithm** (replaces Newton-Raphson for deformable particles):
1. Get surface nodes of particle i in world frame
2. Transform each node to body frame of particle j (rotate by -θ_j, translate)
3. Query SDF of particle j at each transformed node
4. Nodes with SDF < 0 are penetrating: overlap δ_k = -SDF(x_k)
5. Contact normal at each node: n_k = ∇SDF / |∇SDF|
6. Force per node: f_k = E* × δ_k × area_weight_k × n_k (linear penalty)
7. Sum forces, torques across all penetrating nodes

**Hemisphere culling**: Only test nodes on the hemisphere facing particle j (dot product
of node normal with centre-to-centre vector > 0). Eliminates ~50% of SDF queries.

**Validation**: Two overlapping circles — LS-DEM contact force should converge to
Hertzian F = (4/3)E*√R*δ^{3/2} as n_surface_nodes increases. Target: <5% error at 128 nodes.

**Integration points in `new_dem_0.py`**:
- `run()` line 3821: after packing, call `init_lsdem(gs, p)` if enabled
- `compute_forces()` line ~2530: add `if p.deformable_enabled:` branch using
  `find_contacts_lsdem_2d()` instead of `find_contact_superellipses()`
- `compute_forces_3d()` line ~2758: same pattern with 3D functions

### Phase 2: Deformation Modes + Stiffness

**Goal**: Define physically meaningful deformation modes and their elastic stiffness.

**Mode definitions** (for superellipsoid with semi-axes a, b, c):

| Mode | Name | Displacement Φ_α(x) | Physical meaning |
|------|------|---------------------|-------------------|
| 0 | Axial compression | `(-νx/a, -νy/b, z/c)` | Flatten along z, bulge laterally (volume-preserving for ν=0.5) |
| 1 | Prolate-oblate | `(x/a, -y/b, 0)` | Stretch x, compress y (in-plane shape change) |
| 2 | Volumetric | `(x/a, y/b, z/c)` | Uniform expansion (very stiff for ν≈0.49) |

For 2D: drop z-components, modes 0 and 1 only.

**Stiffness matrix K_αβ** (diagonal for orthogonal modes):
```
K_00 ≈ (2/3) × G × V      (deviatoric, G = E/(2(1+ν)))
K_11 ≈ (2/3) × G × V      (deviatoric)
K_22 ≈ 3 × K_bulk × V     (volumetric, K_bulk = E/(3(1-2ν)))
```
where V = particle volume. For ν=0.49: K_22/K_00 ≈ 50× (volume changes heavily penalized).

Units: E[kPa]→E×1e3[Pa], V[µm³]→V×1e-9[mm³]. K in nN/µm follows from dimensional analysis.

**Functions**:
- `compute_mode_stiffness(a, b, c, n1, n2, E, nu, n_modes)` → K (n_modes × n_modes)
- `init_mode_shapes(gs, p)` → sets `gs.mode_shapes_at_nodes` and `gs.K_def`

### Phase 3: Deformation Integration + Semi-Lagrangian SDF

**Goal**: Particles actually deform under contact forces.

**Overdamped deformation ODE**:
```
γ_def dε/dt + K ε = F_ε
```

**Implicit Euler** (unconditionally stable for stiff K_22):
```
(γ_def/dt × I + K) × ε_new = γ_def/dt × ε_old + F_ε
ε_new = solve_3x3(A, rhs)
```

The 3×3 system is trivially cheap — no iterative solver needed.

**Deformation drag**: `γ_def_i = p.def_drag_scale × r_i³` (scales with particle volume).

**Generalized deformation force** from contact:
```
F_ε_α = Σ_k Φ_α(x_k) · f_k    (project contact force onto mode shape)
```
Both particles get deformation forces: particle i (node owner) and particle j (SDF owner).

**Semi-Lagrangian SDF evaluation** (deformed geometry on-demand):
```python
def query_deformed_sdf(sdf_grid, ..., epsilon_j, x_body_j):
    # Pull back to reference config: x_ref = x - u(x)
    u = Σ_α ε_α × Φ_α(x)    # displacement from deformation
    x_ref = x_body_j - u
    return query_sdf(sdf_grid, x_ref)  # query undeformed SDF
```

No grid recomputation — evaluate the analytical mode shapes at the query point to compute
the pull-back displacement, then query the pre-computed (undeformed) SDF at the pulled-back point.

**Integration point in `step()`** (line 2912, after force computation):
```python
F, torques, contacts = compute_forces(gs, p, rng)  # existing

if p.deformable_enabled:
    integrate_deformation_implicit(gs, p)  # NEW: update epsilon
```

The deformation integration happens AFTER force computation (which populates `F_eps_accum`)
and BEFORE translational/rotational integration.

**Stability note**: The implicit Euler for deformation has no CFL constraint. The
translational/rotational integration remains explicit Euler (unchanged from V2.2).
The deformation relaxation time τ = γ_def/K ≈ 0.005 h would require dt < 0.01 h for
explicit Euler, but implicit Euler handles this with dt = 0.5 h without issue.

### Phase 4: 2D Superellipses

**Goal**: Extend from circles to full superellipse shapes.

Changes from Phase 1-3:
- SDF computation uses `superellipse_approx_sdf()` with gradient normalization
- Surface nodes placed via uniform parametric sampling t ∈ [0, 2π)
- Mode shapes adapted for (a, b, n) parameters
- Arc-length weighting for non-uniform node spacing on blocky shapes

---

### Phase 5: 3D Spheres + Superellipsoids

**Goal**: Full 3D LS-DEM.

Changes:
- 3D SDF grids: (res, res, res) per particle. Memory: 500 × 32³ × 8 = 131 MB
- Fibonacci sphere sampling + ray-superellipsoid projection for surface nodes
- Quaternion transforms for world↔body coordinate mapping
- 3D torques: vector cross products (already implemented in V2.2)
- 3D mode shapes with z-component

**Performance target**: With Numba JIT on hot paths (SDF queries, node transforms),
aim for <2× wall-clock overhead vs rigid V2.2 per timestep.

**MC-DEM interaction**: When `deformable_enabled=True`, the MC-DEM post-correction should
be disabled (deformation modes naturally capture multi-contact stiffening geometrically).
Add logic: `if p.deformable_enabled: p.mc_dem_enabled = False`.

|-----------|--------------------|--------------------|
| SDF grids | 4 MB (32×32) | 131 MB (32³) |
| Surface nodes | 1 MB (128 nodes) | 6 MB (512 nodes) |

| Deformation state | <0.1 MB | <0.1 MB |
| **Total** | **~7 MB** | **~155 MB** |

For 3D, reducing SDF resolution to 24 cuts storage to ~66 MB. This is the main tuning knob.

## Backwards Compatibility

When `deformable_enabled=False` (default):
- No SDF/node/mode arrays allocated
- `compute_forces` follows existing V2.2 Newton-Raphson path
- `step()` has no deformation integration
- `render_fields()` uses rigid stamping
- **Zero performance impact** on V2.2 code
