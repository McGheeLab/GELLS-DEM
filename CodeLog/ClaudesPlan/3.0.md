# GELS V3.0 — Fibroblasts on collagen-coated granules: species model, sectioned YAML setup, live view, multi-core engine

## Context

GELS (V2.7; engine `gels/engine.py`, local pipeline `pipeline/step1..5`) models cell-driven rearrangement of
hydrogel granule scaffolds. The lab's actual experiment is **human fibroblasts migrating on a bed of hydrogel
granules coated with Collagen-I to a tunable degree**. Three things are wrong with the code for that:

1. **The physics is binary.** Every granule is "functional" (`gtype=0`, cell-laden) or "inert" (`gtype=1`).
   Adhesion, friction, cell seeding, bridging eligibility, phase fields, metrics and colours all key on that bit
   (~40 engine sites; a 4-entry pair-type LUT at `engine.py:3343-3349` / `3672-3676`; `gtype==0` gates at
   `1448, 1508, 2167, 3427, 3543, 3754, 3852`; two hard-coded phase grids with 5 stampers). The experiment has a
   continuous **degree of functionalization f ∈ [0,1]** (collagen coverage) and mixes several granule **species**.
2. **Parameters are one 112-field flat dataclass** (`Params`, `engine.py:72-249`) with some unphysical defaults
   (`cell_migration_speed = 5 µm/h`; fibroblasts crawl ~12–60 µm/h; `n_motors=50` → 25 nN stall) and no way to
   state values per object (granule species, cell type, domain…).
3. **The engine is single-threaded Python.** Zero parallelism; ~200-line pure-Python bodies per contact pair per
   step (~50 µs/pair measured); an O(N²) ray-cast in `_classify_bridge_path` (`2979-3046`); 2D rendering with no
   bounding box and Ng ∝ √N (`4340-4445`); RSA placement O(800·N²); all snapshots held in RAM. At N=10⁴ a 2D step
   is ~7 s and one render ~40 min. The workstation has 2× Xeon Gold 6148 (40 cores/80 threads) and 511 GB RAM.

Outcome: **V3.0** where granules carry `species_id` + `f` and every f-dependent rule reduces exactly to V2.7 at
f∈{0,1}; a commented, sectioned YAML setup file defines the system and auto-converts the 400 legacy trials; a
`--live` real-time viewer; and numba-parallel kernels that make 10⁴–10⁵-granule runs practical.

## Decisions made with the user

| Decision | Choice |
|---|---|
| Traction vs f | **Revised after the ligand-density literature review (see A.2b)**: saturating Langmuir in *absolute* ligand density, `g(f) = f(1+κ)/(f+κ)`, `κ = K_σ/σ_max` (defaults σ_max = 750, K_σ = 160 molecules/µm² → g(0.2) ≈ 0.59). Power law `f^γ` retained as a selectable alternative (`traction_f_law`). Both reduce exactly to V2.7 at f∈{0,1}. |
| Species mix basis | **Volume fraction** of the total solid (area fraction in 2D) |
| Setup file | **YAML with comments**, sectioned per object (adds `pyyaml`); JSON accepted as the comment-free subset |
| LS-DEM | **Deferred**: keeps working on the existing Python path (off by default); not compiled this round |
| GPU | Out of scope (no CUDA toolkit); design keeps a future CUDA port possible (SoA + pair records) |
| Live view backend | matplotlib **TkAgg in a separate process** (PyVista/VTK is blocked by Windows WDAC here; no Qt) |

## Design resolutions (reconciling the three design studies)

- **`Params` stays flat** — the 5700-line engine keeps `p.X`. The only structured field is `species: list` of plain
  dicts (survives `asdict → json → list(v)`; nested dataclasses would be silently mangled by the coercion at
  `engine.py:5209-5215` / `pipeline/_common.py:204-211`). Nested dataclasses live only in new `gels/config.py`
  and are flattened by `Setup.to_params()`.
- **`gtype` becomes derived, never authoritative**: `gtype = 0 where f ≥ f_min_adhesion else 1`
  (`f_min_adhesion = 0.05`). All of `analysis/`, `viz/`, `viz2/` and the metric keys `phi_f_*`, `n_contacts_ff/if/ii`,
  `disp_func/inert` keep working unchanged.
- **One home for the f-rules**: new `gels/materials.py` (njit leaf functions), imported by both the Python loops
  and the compiled kernels. Rules reduce exactly to V2.7 at f∈{0,1}.
- **Traction coupling is law × rule**, both parameters. `traction_f_law ∈ {langmuir, power}` (default
  `langmuir`) gives `g(f_eff)`; `traction_f_rule ∈ {target, min, product}` (default `target`) picks
  `f_eff` for a bridge: a cell that exists sits on a coated patch of its host, so the uncertain grip is the
  target's. `g` enters the motor-clutch force as a **bond-number prefactor and inside the clutch stiffness**
  (`F = F_stall · k_sub/(k_sub + g·k_opt) · engagement · maturity · g`), never by scaling `n_clutches` — which
  would *raise* traction in this formula (sign trap). Per-cell force is two-sided (`F_cell_i`, `F_cell_j`) using
  the **host's** E, ν, FA maturity. Bangasser 2017 (partial integrin blockade cut traction ~4× uniformly across
  stiffness) is the licence to treat `g` as separable from the stiffness dependence.
- **Storage**: `gs.pos (N,3)`, `gs.vel (N,3)`, `gs.pos_unwrap (N,3)` C-contiguous, with `x/y/z/vx/vy/vz/x_unwrap…`
  as **properties whose setters write through** (so `gs.x = arr` never detaches a view). Index arrays int32
  (`species_id`, `cell_granule_id`, `cell_bridge_target`), `cell_state` int8, physics float64, fields float32.
  E stored in kPa on `gs` (Params units); converted once when packing kernel inputs.
- **Kernels**: pair pass → per-pair records → particle gather over a full CSR neighbour list (owner-writes-only,
  no atomics, bit-identical for 1 or 40 threads); counter-based hashed RNG for per-cell draws (one `Generator`
  draw per step). Naming: `perf_threads` (Params) ↔ `performance.threads` (YAML) ↔ `--threads` (CLI).
- **Live view never blocks the simulation**: bounded `multiprocessing.Queue(maxsize=4)`, `put_nowait`, drop-oldest.
- **Bit-identical legacy compatibility is a hard gate for the Python path** (Phases 1–4): converted legacy trials
  reproduce V2.7 packings and 5-step trajectories exactly. Kernels (Phase 6) are exact for deterministic parts and
  statistically equivalent for stochastic bridging (different RNG consumption, documented).

### A.2 `gels/materials.py` (all `@njit(cache=True)`, reuse the `njit` fallback pattern at `engine.py:56-65`)

```
mix_pair(fi, fj, x_cc, x_cb, x_bb) = fi·fj·x_cc + [fi(1−fj)+fj(1−fi)]·x_cb + (1−fi)(1−fj)·x_bb   # W and τ₀
mix_wall(fi, x_cb, x_bb)          = fi·x_cb + (1−fi)·x_bb                                        # wall = bare
pair_E_star_Pa(Ei_kPa, νi, Ej_kPa, νj) = 1e3 / ((1−νi²)/Ei + (1−νj²)/Ej)   # equals E/(2(1−ν²)) for identical bodies (engine.py:3340)
wall_E_star_Pa(Ei_kPa, νi)        = 1e3·Ei/(1−νi²)                          # matches engine.py:3341
ligand_factor(f, κ)                = f·(1+κ)/(f+κ)        # normalised Langmuir: g(0)=0, g(1)=1, monotone; κ = K_σ/σ_max
traction_gain(f_host, f_target, law, rule, γ, κ) = g(f_eff);  f_eff = f_target | min | product (rule 0/1/2);
                                     g = ligand_factor(f_eff, κ) (law 0) | f_eff^γ (law 1)
blocker_factor(f_blocker, bare_factor)   = bare_factor + (1−bare_factor)·f_blocker
```
Plus numpy helper `build_pair_tables(species_f, species_E, species_nu, p)`.

### A.2b Evidence base for the f→traction coupling (from the ligand-density literature review)

Goes into `CodeLog/References/fibroblast_parameters.md` with the review's verification flags preserved
(`[verified]` / `[numbers verified, framing corrected]` / `[unverified]`):

- **Absolute density, not dilution fraction, is the variable.** Fibroblast ladder (three independent methods agree):
  spreading onset ~5 molecules/µm² (Massia & Hubbell 1991; Gaudet 2003); focal contacts + stress fibres ~50/µm²;
  ligand supply ≈ integrin supply and max spread area at σ* ≈ 150–200/µm² (Gaudet 2003, ≈ the cell's own ~200
  integrins/µm²); FA/traction saturation ~350–500/µm² (Cavalcanti-Adam 2007); no gain beyond ~10³/µm².
- **Gaudet et al. 2003** (Biophys J 85:3329; human fibroblasts, TFM, collagen-I 4.8→750 molecules/µm²) — literally
  this experiment. `[unverified]` Traction is U-shaped (440–590 Pa at 5–100/µm², minimum 260 Pa at ~160/µm²,
  700 Pa at 750/µm²); total force ≈ 400 nN/cell; spread area 600→1300 µm² up to σ*, then declines; migration speed
  peaks separately (~10 µm/h at ~450/µm²).
- **Roberts, Chen & Mrksich 1998** (mixed RGD/(EG)₃OH SAMs — the CH₃-dilution analogue) `[unverified]`: onset at
  χ_RGD = 10⁻⁵, saturation at 10⁻³; converting with alkanethiolate packing gives K_σ ≈ 450/µm² — brackets Gaudet's
  160/µm² within 3×. Hence defaults `sigma_ligand_max = 750`, `K_sigma_traction = 160` (κ = 0.213):
  g(1)=1, g(0.5)=0.86, **g(0.2)=0.59**, g(0.1)=0.41, g(0.05)=0.26. For a saturated RGD monolayer (σ_max ≈ 4·10⁴)
  κ = 0.004 and g(0.2) = 0.98 — dilution is invisible. **Calibrating σ_max matters more than f.**
- **Erdmann & Schwarz 2004** `[unverified]`: critical cluster force `f_c = N_t·plog(γ/e)` is *linear in bond
  number* — so the Balaban "constant 5.5 nN/µm²" is really `ρ_bond·F_b·plog(γ/e)` and falls with engaged-bond
  density. Justifies the prefactor form and **scaling `bridge_lock_force_threshold` with g** (α5β1: F_b = 9 pN,
  γ ≈ 0.2 → ≈ 0.5 pN critical force per bond).
- **Bangasser & Odde 2013** `[numbers verified, framing corrected]`: traction magnitude ≈ `n_m·F_m`; the `1/ln(n_c)`
  appears only in the optimal-stiffness expression; motor and clutch numbers must be balanced (`n_m ≈ n_c`).
  **Bangasser 2017** `[unverified]`: ~4× uniform traction reduction under partial integrin blockade across all
  stiffnesses (separability). **Oria 2017** (Nature 552:219) `[verified 3–0]`: the sign of the ligand-spacing effect
  flips with substrate rigidity — on soft (kPa) substrates, sparser ligands can *grow* adhesions. GELS granules are
  in that regime → documented caveat; not modelled this round.
- **Not supported by the evidence (do not implement):** linear F ∝ density; a hard 58–70 nm percolation threshold
  (moves 62→162 nm with linker length, inverts with rigidity, depends on ligand order at fixed density); a
  density-independent 5.5 nN/µm² (population trend for *growing* adhesions only; use 4 nN/µm² for fibroblasts if
  a stress is needed); `F_per_clutch = F_total/n_clutches`; `F ∝ 1/ln(n_c)`.
- Three papers the defaults lean on hardest (Gaudet 2003, Erdmann–Schwarz 2004, Bangasser 2017) are unverified in
  the review; Massia & Hubbell 1991 was only reached second-hand. Flag in the references file as "verify before
  publication".

### A.4 Species packing, rendering, metrics

## Part D — Compiled parallel compute (`gels/kernels/`)

Measured on this machine: Python pair loop ≈ 50 µs/pair; JKR Newton leaf 91 ns; 2D superellipse Newton 4 µs; 3D
superellipsoid Newton 56 µs (allocation-bound); numba `omp` layer works (`tbb` DLL missing); compute-bound `prange`
scales 34× at 40 threads; memory-bound plateaus ≈ 20 GB/s; **Optional-returning `@njit` leaves cannot be called from
compiled callers** → status-tuple wrappers are mandatory.

- **Dispatcher** in `engine.py`: `if p.deformable_enabled or not (HAS_NUMBA and p.use_numba): reference.*` (LS-DEM lives
  entirely in `kernels/reference.py`, which holds the V2.7/V3-Python loops verbatim) else kernels. Public API names,
  argument order and return types unchanged; `contacts` becomes a `ContactSoA` (`__len__`, `.to_dicts()` adapter).
- **Neighbours** (`neighbors.py`): numba linked-cell grid (parallel count/fill) → half-pair list + full CSR
  (`nbr_off int64, nbr_j int32, nbr_pair int32, nbr_side int8`); per-pair cutoff `rb_i + rb_j + L_max` (exact for the
  restricted ray-cast); Verlet skin `perf_neighbor_skin=20 µm`, rebuild when `2·max_disp + 2·Δr_bound ≥ skin`;
  grow-only capacity. cKDTree→CSR kept as Phase-1 stopgap and test cross-check. One list feeds forces, overlap
  resolution, bridging, metrics, effective radii and packing (today: 2 trees/step + 1 more per save).
- **Forces** (`contact2d/3d.py`): `pair_contacts_*` (prange over half pairs → uncompacted records `c_hit, c_delta,
  c_n*, c_c*, c_Reff, c_Fn, c_a, c_A, c_Ft*, c_d, c_gap`; reuses `jkr_force_from_overlap`, `hertz_contact_force`,
  status wrappers `se2d_contact_k`, `se3d_contact_k`, `sph3d_contact_k`, njit'd `find_contact_wall_3d`; W/τ₀/E* inline
  from `materials`) → `gather_forces_*` (prange over particles: F, torque, `eps_V`, fixed-width clips
  `(N, perf_max_clips, dim+1)`, walls) → `mc_dem_*` (third pass, race-free via side-0 ownership).
  `fastmath={'nnan','ninf','nsz','arcp','contract'}` (no `reassoc` → deterministic), `nogil=True, cache=True`.
  Phase 2b: allocation-free scalar quaternion/superellipsoid math in `geometry3d.py` (56 µs → ≤8 µs target).
- **Cells** (`cells.py`, `rng.py`): per-granule aggregates vectorised in numpy (`cell_cap` static per granule);
  per-cell state machine `cells_update_state_*` (prange over host granules, owner-writes-only); bridging split into
  **B1** `bridge_pairs_*` (prange over FF candidate pairs: gap, path factor via **restricted ray-cast over
  N(i)∪N(j)** (O(Z) instead of O(N)), two-sided `F_cell_i/j`, start-of-step committed counts) and **B2**
  `bridge_cells_*` (prange over granules: service committed bridges, attempts with hemisphere/exclusion/decay).
  RNG: splitmix64 counter hash `u01_hash(seed_step, ci, j, salt)` with one `Generator` draw per step → thread-count
  independent, no per-step allocation. Documented semantic change: same-step bridge visibility across pairs
  (V2.7 sequential artefact) becomes start-of-step; traction acts on host only (as in V2.7).
- **Integration** (`integrate.py`): `integrate_2d`, `rotate_3d` (replaces Python loop 4079-4087), `resolve_overlaps_csr`
  (no second tree), fused clip/wrap.
- **Rendering** (`render.py`): bounding-box stamps; prange over grid slabs with a per-slab granule CSR index
  (race-free, no private grids); ghost images via expanded image list; `0.5(1−tanh)` LUT; compiled renormalisation;
  `effective_radii_from_contacts` (drops the cKDTree at 1256/1298). Grid policy decoupled from N:
  `Ng = ceil(L/perf_field_res_um)` capped at `perf_max_grid_2d=4096` / `perf_max_grid_3d=256`, float32.
- **Metrics** (`metrics.py`): `np.bincount` for cluster sizes (O(grid) not O(nc·grid)); `metrics_from_contacts` over
  this step's records (no third tree, no Python pair loops); Voronoi group fractions via cell list on a stride-4
  sub-grid (or `cKDTree.query(workers=-1)`); shape area/perimeter/circularity computed **once at packing** (rigid).
- **Packing** (`packing.py`): RSA with a cell grid, consuming the same `rng.uniform` draws in the same order →
  bit-identical positions; settle uses the skinned list + compiled gather (7000 tree builds → ~100 rebuilds).
- **Memory / I/O**: no `snaps` in RAM unless `perf_keep_snaps_in_memory`; fields rendered at save steps and dropped;
  `gels/io/writer.py` background thread, bounded queue depth 2, `ZIP_DEFLATED compresslevel=1` via
  `np.lib.format.write_array` (np.load-compatible, 3–4× faster than `savez_compressed`), atomic rename; budget at
  N=10⁵ 2D < 1 GB (V2.7 `snaps` would be ≈95 GB).
- **Threads**: `numba.set_num_threads(perf_threads)` at `run()`/bench start (default 40); `NUMBA_THREADING_LAYER`
  from `perf_threading_layer='omp'` set before importing `gels.kernels` (recommend `pip install tbb` as an option);
  first-touch zeroing inside parallel kernels; `bench.py --threads 40,80` decides HT per machine.
- **Warmup & cache**: `kernels.warmup(dim, shape_mode, periodic, walls)` on a 4-granule system with production
  signatures (`_KernelState` enforces dtypes/contiguity); `ensure_cache_fresh()` hashes `gels/kernels/*.py` and purges
  stale `.nbi/.nbc` (numba does not invalidate callers when an inlined leaf changes); cold compile ≈1–3 min once,
  cached load ≈1–3 s. Verify `cache=True + parallel=True + nogil` on numba 0.67 / Python 3.14 in Phase 0.
- **New `Params` fields**: `perf_threads=40, perf_threading_layer='omp', perf_neighbor_backend='cells'|'ckdtree'|'reference',
  perf_neighbor_skin=20.0, perf_max_clips=16|24, perf_field_dtype='float32', perf_field_res_um=0 (→2·interface_width),
  perf_max_grid_2d=4096, perf_max_grid_3d=256, perf_metrics_voronoi_stride=4, perf_keep_snaps_in_memory=False,
  perf_async_io=True, perf_io_queue_depth=2, perf_io_compresslevel=1, perf_fastmath=True, perf_warmup=True, use_numba=True`.
- **Expected** (order of magnitude): 2D circles N=10⁴ step 7 s → 5–8 ms; N=10⁵ ≈7 min → 30–40 ms; 3D spheres
  N=5·10⁴ ≈15 min → 40–60 ms; 2D render N=10⁵ hours → ≈0.15 s; 2D packing N=10⁵ hours → 10–20 s; full 720-step 2D
  10⁵ run with 180 saves ≈10 min (dominated by `scipy.ndimage.label` in metrics). At N≈10³ the step is
  orchestration-bound (2–5 ms Python floor) and shows little thread scaling — the bench must report this honestly.

## Risks & notes

- Silent parameter loss if alias names are not added to `_common.load_trial_json`'s field set — highest-impact compatibility bug; covered by `test_legacy_identity`.
- Any change to RNG draw order or placement order breaks bit-identical legacy packings — guarded by fixtures; the kernel RNG change is deliberate and documented (per-seed deterministic, not V2.7-comparable).
- `scipy.ndimage.label` on 4096² grids (~0.3–0.5 s × 3) may dominate saves at 10⁵; fall-backs: labelling on a stride-2 grid, numba union-find, or offload to the writer thread.
- Numba 0.67 on Python 3.14 is new — Phase 0 smoke-tests `cache=True + parallel=True + nogil` before anything depends on it.
- `bridge_lock_force_threshold` (20 nN default; 5 nN in trials) and `expected_bridge_force` must be co-tuned with the new motor-clutch defaults (100 nN stall) and with `lock_scales_with_ligand`; flagged in the references doc.
- The Langmuir defaults (σ_max=750, K_σ=160) rest on Gaudet 2003 / Erdmann–Schwarz 2004 / Bangasser 2017, which the literature review left **unverified**; the fit is the reviewer's, not a published equation. Expose both constants in the YAML, keep the power law selectable, and re-verify before publication. Oria 2017's soft-substrate sign flip is a known unmodelled effect.
- Two-population analysis models (`mean_field_model`, `contact_network_model`) are approximations for K>2 — documented, not rewritten.
- Species names may contain spaces → metric keys use indices; names live in `metadata.json`.
