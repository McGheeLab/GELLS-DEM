# V2.4: 2D Packing — Lubachevsky-Stillinger Inflate-and-Relax

## Problem

The 2D packing generator (`generate_packing()`) places granules at **full size** via RSA
(Random Sequential Addition), then runs a gentle centripetal settle. This approach:

1. **RSA saturation**: RSA for monodisperse disks saturates at φ ≈ 0.547. With only 800
   placement attempts per granule, failures begin well before that.
2. **Settle doesn't compress**: `_settle_packing_2d()` attracts granules toward domain center
   while repelling overlaps. It reaches equilibrium with gaps between granules — it does
   NOT produce jammed packing.
3. **3D works fine**: The 3D code uses Lubachevsky-Stillinger (deflate→inflate) which easily
   achieves jammed packings at Z ≈ 4–6.

## Solution

Port the 3D Lubachevsky-Stillinger approach to 2D:

### 1. Deflated RSA in `generate_packing()`

Compute deflation factor (area scales as r², so exponent is 1/2 not 1/3):

```
alpha_deflate = (packing_inflate_phi_safe / phi_target)^(1/2)
```

Use `alpha_deflate * r_bound_val` for overlap checks during RSA. This lets all granules
place easily even at high target φ.

After building GranuleSystem, store target radii and deflate:
```python
gs._target_a = gs.a.copy()
gs._target_b = gs.b.copy()
gs._target_r = gs.r.copy()
gs.a[:N] *= alpha_deflate
gs.b[:N] *= alpha_deflate
gs.r[:N] *= alpha_deflate
gs.r_bound[:N] = np.maximum(gs.a[:N], gs.b[:N])
```

### 2. Rewrite `_settle_packing_2d()` — inflate-and-relax

Mirror the structure of `_settle_packing_3d()`:

- **Outer loop** (`packing_settle_steps`): linearly inflate radii from deflated→target
  with quadratic ease-in (spend more time near α=1 where jamming is hard)
- **Inner loop** (`packing_relax_substeps`): vectorized overlap repulsion + centripetal
  attraction (walls) or jitter (periodic) + velocity cap
- **Post-inflation relaxation**: extra iterations to resolve deep overlaps down to 5% tolerance
- **Progress reporting**: print Z (coordination number) at intervals

### 3. No new parameters

Uses existing `packing_settle_steps` (400), `packing_relax_substeps` (15), and
`packing_inflate_phi_safe` (0.20). These already work well for 3D.

## Expected Outcome

- 2D packing achieves Z ≈ 3–4 (2D jamming) instead of Z ≈ 0–1
- Granules in mutual contact from t=0
- Consistent with 3D packing quality
