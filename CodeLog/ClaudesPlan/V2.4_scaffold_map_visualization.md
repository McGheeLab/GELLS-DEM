# V2.4: Vector Scaffold Map Visualization

## Problem

The composite visualization (`plot_composite`) relies on grid-based phase field rendering
(`render_fields()`), which suffers from aliasing artifacts when `Ngrid` is too coarse
relative to the domain size. On large domains (Lx=2319 µm with Ngrid=200), the 3 µm
`interface_width` occupies only 0.26 pixels, producing binary pixel noise that appears as
randomly distributed rectangular void patches in the rendered fields.

These artifacts affect not only the visual output but also any analysis metrics derived
from the phi fields (connectivity, porosity, tissue fraction, etc.).

## Solution

Replace the grid-based composite image with a **vector-drawn scaffold map** using
matplotlib patches (circles/superellipses). This approach:

1. Draws granules as exact geometric shapes — no grid discretization, no aliasing
2. Colors by type: **red** = functional, **green** = inert, **black** = void
3. Overlays individual cells using cell-state colors (matching `viz/cells.py`)
4. Handles periodic boundary ghost images for particles near domain edges
5. Produces clean output at any resolution via DPI scaling

## Changes

### `viz/postprocess.py`

1. **New function `plot_scaffold_map()`**: Vector-drawn scaffold visualization
   - Black background with red/green granule patches
   - Per-granule type coloring via `PatchCollection`
   - Periodic ghost images for boundary-crossing particles
   - Cell overlay with state-specific rendering (circles for attached/spreading/proliferating/senescent, ellipses for bridging/migrating)
   - Legend with both granule types and active cell states
   - White text/axes for contrast on black background

2. **Pipeline update**: Step [4/17] now produces `scaffold_map.png` (vector, always available)
   plus `composite.png` (legacy, only when phi fields exist). The skip key remains `'composite'`
   for backward compatibility.

3. **Import additions**: `Ellipse`, `PatchCollection`, `Line2D` from matplotlib

## Rendering Approach Comparison

| Aspect | `plot_composite` (grid) | `plot_scaffold_map` (vector) |
|--------|------------------------|------------------------------|
| Method | Stamp tanh profiles onto Cartesian grid | Draw exact patches |
| Resolution | Fixed by Ngrid | Infinite (vector) |
| Aliasing | Yes, when dx > interface_width | None |
| Periodic BCs | Via ghost field stamping | Via ghost patch drawing |
| Cells shown | No | Yes, colored by state |
| Analysis use | Direct pixel counting | Rasterize at any target DPI |
| Speed | ~1s per snapshot | ~0.5s per snapshot |

## Verification

Tested on DOE_2D_0001 (Lx=1763 µm, N=250 granules, 777 cells, periodic BCs).
Output shows clean granule boundaries, clearly defined void space, and visible
cell populations at all timepoints.
