# V2.1 Two-Compartment Volume Conservation Analysis

## Problem
The simulation should conserve total solid volume globally:
- `phi_f_global + phi_i_global = phi_solid = CONSTANT`
- `phi_v_global = 1 - phi_solid = CONSTANT`

Locally, functional zones compact (less void) while inert zones may expand (more void).
Current metrics only report domain-averaged phi values — no way to confirm local
redistribution is happening correctly without global leakage.

## Approach: Voronoi Shrink-Wrap

Assign each voxel in the domain to the **functional compartment** or **inert compartment**
based on which granule type is nearest (Voronoi tessellation by phase). This "shrink-wraps"
each phase's territory tightly around its granules, naturally excluding islands of the
opposite phase.

### Algorithm
1. Build `cKDTree` of all granule centres (with `boxsize` for periodic BCs)
2. Create a 3D grid of voxel centres
3. Query nearest granule for each voxel → assign to functional or inert compartment
4. Compute metrics within each compartment separately

### Why Voronoi?
- Handles periodic BCs natively via `cKDTree(boxsize=)`
- No arbitrary thresholds or morphological tuning parameters
- Physically meaningful: each granule "owns" the space closest to it
- Naturally handles mixed/interpenetrating packings
- Fast: O(N_voxels × log N_granules) with KD-tree

## Metrics

### Global Conservation (sanity check)
- `phi_f_global(t)` — should be constant
- `phi_i_global(t)` — should be constant
- `phi_v_global(t)` — should be constant
- `phi_solid_global(t) = phi_f + phi_i` — should be constant

### Compartment Volumes
- `x_f(t)` — fraction of domain volume in functional compartment
- `x_i(t) = 1 - x_f(t)` — fraction in inert compartment

### Local Phase Fractions (within each compartment)
**Functional compartment:**
- `phi_f_local(t) = mean(phi_f) over functional voxels`
- `phi_v_func(t) = mean(phi_v) over functional voxels`
- `phi_solid_func(t) = mean(phi_f + phi_i) over functional voxels`

**Inert compartment:**
- `phi_i_local(t) = mean(phi_i) over inert voxels`
- `phi_v_inert(t) = mean(phi_v) over inert voxels`
- `phi_solid_inert(t) = mean(phi_f + phi_i) over inert voxels`

### Expected Behavior
- `phi_solid_global` stays flat (conservation)
- `phi_v_global` stays flat (conservation)
- `x_f` decreases over time (functional zone compacts, shrinks)
- `phi_solid_func` increases (granules pack tighter in functional zone)
- `phi_v_func` decreases (void expelled from functional zone)
- `phi_v_inert` increases (void redistributes to inert zone)
- Cross-check: `x_f * phi_v_func + x_i * phi_v_inert = phi_v_global`

## Implementation

### New module: `analysis/volume_conservation.py`
- `voronoi_compartments(gs, p, grid_shape)` → (func_mask_3d, inert_mask_3d)

- `conservation_from_run(run_dir)` → DataFrame with all metrics per timepoint
- `plot_conservation(df, output_dir)` → 4-panel figure

### Integration into compute_metrics() in new_dem_0.py
Add lightweight per-timestep tracking:
- `x_f`, `phi_v_func`, `phi_v_inert` to history dict
- Uses the same Voronoi approach but on the coarser Ngrid_3d grid

### Visualization (4-panel figure)
1. **Global conservation**: phi_f, phi_i, phi_v vs time (flat lines = good)
2. **Compartment volume**: x_f, x_i vs time
3. **Local void**: phi_v_func, phi_v_inert vs time (should diverge)
4. **Cross-check**: x_f*phi_v_func + x_i*phi_v_inert vs phi_v_global (should overlap)
